# Portofolio Ferdi Algafar

## Menjalankan
1. Buka folder ini di VS Code.
2. Pasang ekstensi "Live Server", klik kanan `index.html` > Open with Live Server.
   (Jangan buka dengan klik ganda: Showreel/audio butuh http://.)

## Yang perlu Anda lakukan
- **Video Google Drive**: untuk tiap file (Good Day, IndiHome, APP Fair) klik Share > "Anyone with the link" > Viewer.
  Jika tidak, pemutar di modal tampil kosong/minta login.
- **Musik showreel**: taruh `showreel.mp3` di `assets/audio/` (lihat catatan di folder itu).
- **Teks & angka karya**: semua ada di `data/works.js`. Jangan ubah HTML untuk itu.
- **Warna/tema**: `css/tokens.css`.

## Struktur
index.html · css/(tokens, base, sections, effects) · js/(main, marquee, workflow, bg-reactive, showreel, lightbox) · data/works.js · assets/

## Publikasi (GitHub Pages)
Unggah seluruh isi folder ke repo `ferdialgafar.github.io` (branch main), tunggu 1-2 menit.
